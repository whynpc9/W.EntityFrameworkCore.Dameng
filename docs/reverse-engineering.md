# 反向工程

本文描述 `dotnet ef dbcontext scaffold` 和 `IDatabaseModelFactory` 的当前支持范围。提供程序只反向工程能够完整保留语义的对象；无法保真的结构会明确拒绝，而不是静默省略或重建成功能不同的对象。迁移操作见[迁移指南](migrations.md)，证据层级见[兼容性矩阵](compatibility.md)。

## 当前模式与对象筛选

- 只扫描 `SF_GET_SCHEMA_NAME_BY_ID(CURRENT_SCHID())` 判定的当前模式，支持 `SET SCHEMA` 后与登录用户不同的模式。当前模式名称为空或不可读时拒绝。
- 覆盖当前模式的表、视图、列、默认值、表/列注释、主键、唯一约束、普通索引、外键、IDENTITY、序列默认值与非键虚拟计算列。标识符按目录原始拼写加引号，不强制大写。
- `--schema` 请求其他模式，或 `--table` 中任一条目限定其他模式，都会点名拒绝。显式请求的当前模式表/视图必须全部命中，否则列出未命中名称并拒绝返回部分模型。
- 模式/表筛选按标识符组成部分解析：未引用部分折成大写；双引号中的大小写、点和转义引号保持原义。
- 表名不超过 128 个时，目录查询使用参数化名称谓词；超过该数量保留完整模式扫描和内存过滤，不丢弃对象。该优化只减少目录传输，不构成延迟或性能保证。
- 当前模式的全部可见序列独立枚举，不受表筛选限制。没有选中表或模式内没有表时，序列仍进入模型；任何不可精确保留的当前模式序列都会阻止整个反向工程，不能靠筛选其他表绕过。
- 表过滤可以隔离大多数不支持的表/视图结构，但不能用来省略选中从表所需的主体、列或关系。

## 列、类型与注释

### 目录完整性与类型映射

- 普通表列读取 `ALL_TAB_COLS`；视图仍按原投影读取。列加入模型前，复用注入的 `IRelationalTypeMappingSource` 按完整存储类型查找映射。映射缺失时点名表/视图、列和类型并抛出 `NotSupportedException`，不让 EF 仅警告后省略列。
- 选中普通表还会按 `Ordinal` 列名集合核对原生预检与兼容列目录；缺列、额外列或没有可读原生列均在返回模型前拒绝。视图与过滤排除对象不参与核对。原生 `COLID` 从 0 起、兼容 `COLUMN_ID` 从 1 起，不按序号差异判定目录损坏。
- BFILE、TIME WITH TIME ZONE、INTERVAL HOUR TO MINUTE，以及包含不支持列类型的视图，均有真实拒绝与普通过滤隔离回归。
- 主键、唯一约束、索引和外键都要求完整列元数据；缺列、零列或索引目录头存在但没有可读列行时明确拒绝。目录缺损由合成单元测试验证，不声称真实服务器曾出现目录损坏。
- 列名查找使用每次反向工程独立的 `Ordinal` 字典，不跨扫描缓存。

### 字符与长度分面

- `CHAR` / `VARCHAR` / `VARCHAR2` 按 `CHAR_USED` 明确保留 `n CHAR` 或 `n BYTE`；未知或 NULL 单位点名对象、列和实际值并拒绝。显式类型名称与左括号之间的空格/制表符会从映射查找基名去除，原始类型文本、长度和单位仍保留。
- `CHAR` / `BYTE` 长度限定只对上述三种类型解析；例如 `INT(9 CHAR)` 不会被降级成 `INT` 后继续生成非法 DDL。
- 自动推导的非 Unicode 定界字符串使用 `VARCHAR2(n CHAR)` / `CHAR(n CHAR)`。变长按最小受支持页的保守 1900 字节预算推导，即最多 475 个字符；更大变长使用 CLOB。定长超过预算时明确拒绝，要求显式的实例特定存储类型或改用变长列，不自动转换成二进制。显式存储类型原样保留，由使用方核对实例页大小和整行预算；建表成功不等于能存满声明长度。
- 反向工程保留 BYTE 列后，相关 CREATE/ADD/ALTER DDL 前生成 `SF_GET_LENGTH_IN_CHAR()=0` 守卫，其他或未知模式拒绝。当前真实验证环境是模式 0，未把模拟拒绝分支当作模式 1 实例验证。
- `NVARCHAR2(n)` 本身使用字符语义，不改写为字节单位。

### 时间、数值与其他分面

- `FLOAT(p)` 按目录 `DATA_PRECISION` 保留二进制精度。
- `INTERVAL DAY TO SECOND` 从 `DATA_PRECISION` / `DATA_SCALE` 还原天精度与秒小数位。
- `TIME` / `TIMESTAMP` / `DATETIME`（含 `WITH TIME ZONE`）按 `DATA_SCALE` 还原精度，显式 `(0)` 不回落为服务器默认值。
- `TIMESTAMP WITH LOCAL TIME ZONE` 的目录 `DATA_SCALE` 带 4096 偏移，按偏移还原精度。

### 可见性、加密、生成标记与触发器

- 普通表的 `HIDDEN_COLUMN` 只接受 `NO`；NOT VISIBLE、未知状态或 NULL 均拒绝，避免改变 `SELECT *` 和无列清单 INSERT 的行为。
- 普通表列读取原生 `SYSCOLUMNS.INFO2`。位 14 标记的加密列和未知标记明确拒绝，不读取密钥目录。
- 位 4/6 的 DEFAULT ON NULL、ON UPDATE 拒绝；位 5 的隐式 NOT NULL 不单独拒绝。
- 选中表或视图存在触发器即拒绝，包括禁用触发器，避免静默丢失触发器定义与状态。
- 表/列注释可读取；服务器不接受 `COMMENT ON` 视图，因此不声称支持视图注释。

## IDENTITY、序列与默认值

### IDENTITY

- 自增识别使用原生目录：`SYSCOLUMNS.INFO2` 位 0 与 `SYSOBJECTS.INFO6` 第 25–26 字节共同判定完整 IDENTITY 类型。`AUTO_INCREMENT` 与未知/缺失生成类型明确拒绝，不当作 IDENTITY。
- 只有确认是 IDENTITY 后才按模式和表名读取 `IDENT_SEED` / `IDENT_INCR`，不会对 AUTO_INCREMENT 调用这些函数。分面查询每批最多 64 张表、128 个参数，不再逐表查询。
- 注解前复用模型最终化的 CLR 兼容性判断，只接受映射为 `int` / `long` 的 IDENTITY 列。`DEC(n,0)` 等其他 CLR 类型点名拒绝。

### NEXTVAL 与本地序列依赖

- 简单 `序列.NEXTVAL` 默认值与仅存在同名序列是两回事；只有实际默认表达式才建立自增关系。
- NEXTVAL 识别支持未引用名称中的 `$`、`#`，限定点号两侧允许空格、制表符和换行；引用名称内部的点、空格与转义引号保持原义。
- 本地序列一律用目录解析出的模式限定。整数 CLR 类型使用提供程序序列策略；`DECIMAL` / `NUMBER` 等非整数列保留限定模式的默认 SQL，序列定义仍进入模型。
- 未限定或当前模式的简单 NEXTVAL 必须读到本地序列目录，否则点名对象、列和序列并拒绝。只有显式跨模式引用可保留为外部依赖。
- 非简单默认 SQL 中若出现未限定或当前模式的 NEXTVAL/CURRVAL 依赖，同样明确拒绝，避免保留表达式却遗漏序列定义。字符串、注释、函数调用和已限定外模式依赖不会被误判为本地序列。
- 默认 SQL 列若属于主键，或被选中外键提升为候选键，而没有受支持的 IDENTITY/Sequence 键生成策略，会点名表、列和类型并拒绝；普通非键默认 SQL 不受此限制。

### 序列分面

- 当前模式的全部可见序列从 `ALL_SEQUENCES` 读入起点、增量、上下界和循环标记，包括独立使用或未被任何列引用的序列。
- 非循环且未耗尽时，`LAST_NUMBER` 是下一个待发放值；未消费时等于 `START WITH`，消费 NEXTVAL 后按增量前移。
- 最小值必须小于最大值。非循环续号越界拒绝。循环序列到达边界时，只有目录续号是从界内前值按正确方向迈出的一步，才按官方循环规则还原为另一端起点；其他不一致状态拒绝。
- 任一 facet 超出 EF 可精确表示范围（非零增量为 `int`，其余为 `long`），或循环标记未知时拒绝。
- 本地序列只接受 `CACHE_SIZE=0`、`ORDER_FLAG=N`；其他或未知缓存/排序状态拒绝。生成的 CREATE SEQUENCE 显式带 `NOCACHE NOORDER`，ALTER 不改未建模的缓存/排序分面。
- 序列目录每次按当前模式完整查询，只绑定一个模式参数，不再按列引用名称分批。

## 约束、索引与外键

### 主键、唯一约束与普通索引

- 保留主键、唯一约束、普通索引及升降序。主键后备索引的 `INDEX_TYPE` 用于保留聚集方式，经 `Dameng:IsClustered` 进入脚手架模型与迁移 DDL，显式生成 `CLUSTER PRIMARY KEY` 或 `NOT CLUSTER PRIMARY KEY`；未知类型拒绝。
- 唯一约束按 EF 脚手架契约转成唯一索引。主键/唯一约束的后备索引不重复建模为普通索引。
- 表达式/函数索引明确拒绝：既检查 FUNCTION-BASED 类型头，也拒绝 `COLUMN_POSITION` 非正或缺失的列行，避免遗漏唯一表达式约束。
- 位图等非 NORMAL 索引、独立用户聚集索引以及非 NORMAL 后备索引的唯一约束拒绝；系统行存储索引不误判为用户索引。
- 普通及聚集物理索引必须 `STATUS=VALID`，且原生 `SYSINDEXES.XTYPE` 的不可见位 65536 未置位。INVISIBLE、UNUSABLE 和未知状态均拒绝，包括主键/唯一约束后备索引；恢复 VISIBLE/REBUILD 后可重新读取。
- 外键的 VIRTUAL 索引是约束实现细节，不作为普通索引，也不进行物理状态/表空间比较；WITH INDEX 创建的普通物理外键索引仍保留。
- 选中表上的用户 CHECK（包括禁用和显式 IS NOT NULL 检查）拒绝；普通列 NOT NULL 不受影响。
- 主键、唯一约束和外键只接受启用、`NOT DEFERRABLE`、`IMMEDIATE`、`VALIDATED` 状态；禁用、延迟、未验证或未知状态拒绝。

### 外键关系

- 选中从表的外键按 `R_OWNER` 判定主体模式。跨模式主体、同模式但未选中/不可读的主体、列目录不完整或无法解析时明确拒绝，不能省略关系。
- 外键引用的主体唯一列若可空则拒绝，避免 EF 候选键把它强制改成不可空；未被选中关系引用的可空唯一列继续保留。
- 更新/删除动作以原生 `SYSCONS.FACTION` 为准：更新只接受空格标记的 NO ACTION；删除保留空格/C/N 对应的 NO ACTION/CASCADE/SET NULL。SET DEFAULT 和其他/未知动作拒绝。参考实例的兼容视图会把删除 SET DEFAULT 错显为 CASCADE，不能据此推断动作。
- 参考实例对未指定 MATCH、MATCH SIMPLE/FULL/PARTIAL 使用相同默认匹配行为，且 TABLEDEF 不保留 MATCH。当前实现不虚构原生匹配模式字段，也不把该实例行为外推为所有版本的 FULL/PARTIAL 语义保证。

## 虚拟计算列

- 通过 `SYSCOLINFOS.INFO1` 位 0 识别虚拟计算列，从 `SYSCOLUMNS.DEFVAL` 保留表达式到 `ComputedColumnSql`，设置 `IsStored=false` 与 `OnAddOrUpdate`，不把表达式当插入默认值。
- 表达式缺失、计算生成键、虚拟列参与主键或被选中外键引用为候选键时拒绝。
- 只支持非键虚拟计算列；存储计算列不属于反向工程或迁移支持范围。
- 表达式中的函数等外部依赖仍由目标环境提供，反向工程不会创建这些依赖。

## 物理存储分面

### 表类型与存储方式

- 普通 B 树表保留 `Dameng:IsClusterBtree=true`，经实体、关系表注解与迁移显式生成 `STORAGE(CLUSTERBTR)`，不依赖目标 `LIST_TABLE` 缺省。堆表或未识别存储拒绝；存储方式变更须重建，未配置该注解的手写模型保持原建表行为。
- 原生 `SYSOBJECTS.INFO3` 低六位只接受普通表类型 0。HUGE 和未知/其他非普通表类型拒绝。
- `INFO3` 位 57 标识的物化视图预建表拒绝，不作为普通表重建；位 50 标识的 LONG ROW 表同样拒绝，因为 CLUSTERBTR 注解不能保留该独立存储能力。
- 全局临时表（事务级/会话级）、未知 TEMPORARY 标记、PARTITIONED 非 NO 或未知标记均拒绝，避免重建为持久或非分区表。

### 表空间与配额

- 表对象 `SYSOBJECTS.INFO2` 的空间页数上限必须为 0（无限制）；非零、缺失或未知 DISKSPACE LIMIT 拒绝，避免重建时移除资源上限。
- B 树表的聚集存储索引 `SYSINDEXES.GROUPID` 必须等于模式所属用户 `SYSOBJECTS.INFO3` 低 16 位的默认数据表空间 ID。通过模式对象 PID 关联所属用户，不以模式名或登录用户替代，也不新增 DBA_USERS 查询权限要求。
- 其余 NORMAL 物理索引（普通二级、非聚集主键、唯一约束及 WITH INDEX 外键）按所属用户 `INFO3` 第 16–31 位校验默认索引表空间。字段为 0 表示未单独配置，可按服务器规则回退到已接受表的数据空间；其他非默认或未知位置拒绝。
- 不声称保留显式非默认表空间；外键 VIRTUAL 索引不进行物理空间比较。

### 填充因子

- 表填充因子从原生 `SYSOBJECTS.INFO1` 高字节读取，经 `Dameng:TableFillFactor` 进入实体、关系表和迁移，显式生成 FILLFACTOR。0 按官方定义归一化为 100，未知/越界拒绝，后续变更须重建。兼容视图 PCT_FREE 不作为读取依据。
- 普通索引和唯一约束后备索引从原生索引对象 `INFO1` 低字节读取，经 `Dameng:IndexFillFactor` 保留到 `CREATE INDEX STORAGE(FILLFACTOR n)`，0 同样规范为 100。
- 聚集存储/主键后备索引只接受与表相同的有效填充因子，否则拒绝，避免重建时丢失独立物理配置。

## 证据边界

- 表、视图、字符/时间分面、IDENTITY/序列、关系、虚拟列、存储注解和上述大多数拒绝路径都有真实库回归；CLI 生成代码还会重新编译并执行模型断言。
- 目录缺行、缺失或未知标记等无法稳定由服务器制造的防御性分支使用合成单元测试，不冒称真实服务器证据。
- 参考实例上的目录布局和行为不构成所有 DM8 版本、兼容模式、页大小或表空间配置的保证。尤其未真实运行 4 KB/8 KB 实例，非默认表空间、列级 COLLATE、视图注释和其他未列结构不因此获得支持声明。
