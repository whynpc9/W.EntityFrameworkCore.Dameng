- 主代理负责设计、代码审查、范围决定与证据汇总。

- 真实库连接由环境变量提供，禁止打印或提交；没有真实库结果的能力不得标为已验证。

## 首轮发现与修复

- Q0 首轮真实库 3 项失败：纯空格通过字符串等值判断被当成空串，20,000 字中文 NCLOB 拼接报字符串截断。前者改为 `IS NULL OR LENGTH(value)=0`；复测构建零警告/零错误、单元 20/20、nullable Unicode/NCLOB 两种空值模式真实测试 2/2 通过。当时长拼接尚未解决，因此未计 Q0 完成；后续修复见下文。
- Q1：ABS(int) 返回 BIGINT，包括将 int.MinValue 变成 2147483648，必须保护 CLR int 范围；ABS(long.MinValue) 在服务器报溢出。其余已探测正常样本不代表全重载完成。
- Q5：HH24、MI、IW 和 DATEPART quarter 的候选 SQL 有结果证据；SS 格式报错，首版不发布秒截断。
- Q2 的 LOG 参数顺序为 base、value；探针最初名为 base_one 的 `LOG(100,1)` 实际不是底数 1，须以修正后的查询为准。
- S1/S4 首轮 DateTime 回读出现第七位小数丢失，必须用服务器文本输出对照驱动读取，不直接归因于服务器。
- Q4/Q5/S1–S4 探针的测试绿色仅表示测量执行完成，每个 case 的结果/错误单独审查，不能计作功能验收通过。

失败发生在 `COALESCE(NCLOB, VARCHAR 空串)` 内部。将回退空串在 COALESCE 内转换为
