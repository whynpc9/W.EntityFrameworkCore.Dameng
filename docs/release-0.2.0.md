# 0.2.0 发布准备

检查日期：2026-09-29。候选版本：`0.2.0`。
已发布基线为 NuGet `0.1.2`（标签 `v0.1.2`）；本文件不表示 `0.2.0` 已发布。

## 相对 0.1.2 的变化

- 扩展基础字符串翻译，补充 `IsNullOrEmpty`、多参数 `Concat`、字符串 `+` 和常量
  BMP 字符/字符数组的 `Trim`、`TrimStart`、`TrimEnd`，并修复 NCLOB 空值回退的类型保持。
- 增加已验证的 `Math` 常用数值、指数与对数函数翻译；对整数 `Abs` 溢出和非有限
  浮点参数保留显式边界。
- 增加带提供程序前缀的日期分桶函数，以及 `DateTimeOffset` 年、月、日、时、分、秒
  成员翻译。
- 增加有界可变文本上的 `string.Join` / `string.Concat` 分组聚合，保留筛选、排序、
  null/空元素位置，并明确拒绝 LOB、固定长度文本和 `Distinct` 等未验证结构。
- 扩展集合 `Contains` 的真实库回归，覆盖空集合、null、重复值、否定、分页和最多
  2,000 个元素的样本；该规模不是服务器容量或性能上限声明。
- 增加统一的本地测试入口、持久测试空间管理、脱敏 TRX 证据和查询能力说明。
- 发布工作流在 NuGet.org 推送成功后创建 GitHub Release，并由 GitHub 根据当前标签与
  之前版本自动生成 Release Notes；预发布标签自动标记为 prerelease。

## 保留边界

- JSON 标量读取和小数 `DateTime.Add*` 未达到无损门槛，本版本不发布相应能力。
- `DateTimeOffset` 的偏移量、UTC 转换、当前时间和 `Add*` 未实现。
- 字符串聚合过长时由服务器报错，不静默截断；无显式排序时不承诺结果顺序。
- 未增加反向工程支持，也不把四项规范冒烟测试描述为上游 EF 关系数据库一致性测试。
- EF Core 10 与 `DM.DmProvider` 的锁定版本范围保持不变。

## 发布流程

1. 完成候选验证并将最终结果回填本文件，确认连接字符串和本地证据未进入 Git。
2. 提交版本、发布记录和工作流修改，复核提交后工作树为空。
3. 推送提交，再在该提交上创建并推送 `v0.2.0` 标签。
4. 标签工作流重新锁定还原、构建、运行单元测试、打包并推送 NuGet.org；只有 NuGet
   发布成功后才创建 GitHub Release 和自动生成的 Release Notes。
5. 核对 GitHub Actions、GitHub Release，并从 NuGet.org 公共索引读取 `0.2.0` 的版本、
   依赖范围和包内容。本地真实库回归与标签工作流证据必须分别保留。
